
# VolFix

Software de diagnóstico en tiempo real para reparación de dispositivos móviles.

## ¿Qué es VolFix?

VolFix es una herramienta de escritorio diseñada para técnicos en electrónica que reparan celulares. Combina la capacidad de cargar esquemáticos propios con medición en tiempo real mediante hardware periférico conectado por USB, potenciado por un asistente de inteligencia artificial.

## ¿Qué lo hace diferente?

A diferencia de herramientas como Borneo Schematics, VolFix no depende de una base de datos cerrada. El técnico carga sus propios esquemáticos y el software los convierte en una herramienta de diagnóstico interactiva en tiempo real.

## Características principales

- Carga de esquemáticos propios (PDF, imágenes)
- Diagnóstico en tiempo real mediante puntas de tester y conectores USB
- Visualización interactiva del esquemático durante la medición
- Asistente de IA integrado para interpretación de diagnósticos
- Historial de casos por dispositivo
